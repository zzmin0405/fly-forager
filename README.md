# 초파리 포레이저

브라우저 안에서 FlyWire 연결망을 계산해 먹이를 수집하는 3D 복셀 실험입니다.

## 실행

프로젝트 폴더에서 `python -m http.server 5198 --bind 127.0.0.1 --directory dist` 후 `http://127.0.0.1:5198`에 접속합니다. Python은 정적 파일 제공용이며 신경망 계산은 브라우저 Web Worker에서 실행합니다.

## 실제 데이터와 인공 규칙

- `dist/connectome.bin.gz`: snedea/flybrain에서 가공한 실제 FlyWire v783 연결 데이터. 139,255개 뉴런, 2,698,236개 방향성 연결.
- `dist/brain.js`: 도착 뉴런별 연결 강도 정규화와 3단계 tanh rate 계산. 감각 뉴런 일부를 4채널로 임의 배정하며, 연결망 자극 반응의 선형 역변환을 출력 디코더로 사용합니다.
- `dist/app.js`: 먹이·위험을 좌우 신호로 바꾸고 디코딩된 신호를 회전에 사용합니다. 기본 전진, 탐색 편향, 충돌 시 회전은 수작업 규칙입니다.
- 각 관측은 독립적으로 계산합니다. 장기 기억, 강화학습, 원 논문의 LIF 재현은 없습니다.
- 뇌 연결 데이터가 없거나 계산이 실패하면 게임이 멈춥니다. 다른 제어기로 자동 대체하지 않습니다.
- 따라서 이 구현은 실제 그래프를 실행하는 게임용 실험이며, 초파리가 자율적으로 게임 전략을 학습했다는 증거가 아닙니다. 인공 입출력과 보정기가 행동을 크게 좌우합니다.

## 조작

자동 플레이를 관찰하고 경기장을 클릭해 먹이를 추가합니다. 키보드는 ‘먹이 놓기’ 버튼과 일시 정지 버튼으로 사용할 수 있습니다. 목표는 에너지가 소진되기 전에 먹이 12개를 수집하는 것입니다.

## 검증

`node verify.mjs`: 실제 데이터 로딩, 4개 감각 채널의 독립성, 혼합 입력, 0 입력, 잘못된 입력을 확인합니다.
브라우저에서 로딩, 플레이, 일시 정지, 재시작을 별도로 확인합니다.
WebMCP 지원 브라우저에서는 `read_game_state`, `place_food` 도구를 제공합니다.

출처 및 이용 조건은 `dist/NOTICE.txt`를 참고하세요.


## 3D 렌더링

Three.js 0.186.0으로 블록 지형, 나무, 바위, 복셀 초파리, 그림자, 궤적을 렌더링합니다. 게임 충돌과 신경망은 기존 평면 좌표를 사용하고 렌더링할 때 XZ 좌표로 변환합니다. OrbitControls로 카메라를 회전·확대하며 Raycaster로 바닥 클릭 위치를 게임 좌표에 대응시킵니다.

anime.js 4.5.0은 먹이 생성, 획득 파편, 점수 강조와 카메라 전환에 사용합니다. 의존성은 `npm ci` 후 `npm run vendor`로 정적 파일에 복사합니다. 배포판은 외부 CDN 없이 라이브러리를 직접 제공합니다. 브라우저의 동작 줄이기 설정에서는 강조 효과를 줄입니다.

검증: `npm run check` 통과. 브라우저에서 3D 로딩, 실제 먹이 수집, 일시 정지, 위에서 보기, 바닥 클릭으로 먹이 추가와 카메라 드래그 시 먹이 미추가를 확인했습니다.
